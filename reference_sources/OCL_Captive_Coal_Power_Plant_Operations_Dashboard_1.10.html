Admin settings are stored with this dashboard and shared with everyone who opens it. Click a section below to expand it.
Online Excel Data Link
▸
Only URLs that allow cross-origin (CORS) requests can be fetched directly by the browser. Most consumer OneDrive/Google Sheets links will not work without a small backend proxy — a raw file host (e.g. GitHub raw, or CORS-enabled storage) works reliably.
Calculated Data Fields
0▸
Formulas may reference input fields (L1_<field>, L2_<field>, P_<field>), baseline constants (B_<key>, e.g. B_turbineCapacityMW), enthalpy helpers (ENTH_HF, ENTH_HS_BOILER, ENTH_HS_TURBINE), the day-of-year helper (DAY_OF_YEAR), Excel-like functions (MOD(a,b), IF(cond,a,b), MIN(...), MAX(...), ABS(a)), and any calculated field listed above it — see the Register tab for the full reference. Put a field On Hold to keep it (and anything that depends on it) working behind the scenes while hiding it from the Dashboard and Report — a safer alternative to removing it outright.
Baseline: Design Constants
0▸
Quantity is informational (e.g. "per boiler" x 2 lines) — formulas always use the Value as entered, not Value × Quantity, so existing calculations aren't silently changed. Reference a constant in a formula as B_<key>.

Settings Backup (Export / Import)
▸
Admin settings save automatically to this dashboard's hosting environment, which covers reopening later or on another browser/device in the normal case. If you're running this file fully standalone (downloaded and opened directly, with no hosting environment behind it), use Export to save a small settings file, and Import to restore it anywhere — the most reliable way to carry settings between separate copies of this app.
